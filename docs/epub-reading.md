# EPUB 原文与译文阅读

## 按章手动翻译（2026-10-09，合入 PDF 控制分支）

EPUB 导入后只提取正文，不自动全文翻译。工具栏的“翻译本章”按当前原文或译文位置选择章节：采用顶层目录，顶层只有书名节点且有子目录时使用其下一级；没有目录时按阅读顺序中的 XHTML 文件划分。同一文件内的目录片段可区分章节，一个章节也可以跨多个文件。无法解析目录锚点时提示错误，不扩大到整书。

每次请求完整章节，与 PDF 章节共用入队逻辑，并复用论文的分批翻译、并发执行和逐段保存流程。已完成译文复用；长章节自动分批，无需再次点击。未请求的段落为 `idle`，可单独翻译，译文订阅接受该状态。暂停、继续、失败重试复用共享任务控制，EPUB 不进入 PDF 版面解析。已请求且排队的段落在重启后继续，暂停状态不会因重启解除。

首次升级时，旧 EPUB 自动任务暂停，未完成的翻译记录改为 `idle`，已完成译文、阅读进度和批注保留。迁移有持久标记，后续启动不会重置手动任务。无旧处理记录的 EPUB 建立等待按章请求的状态。

## 当前章节与工具栏状态（2026-11-08）

图书（EPUB 与图书库 PDF）的翻译按钮只反映当前章节。当前章节由一个锚点段落决定：点击或选中段落、目录或链接跳转、点击“翻译此段”时立即固定到该段；此后滚动停下时改为视口中线处的段落（PDF 未解析页取当前页）。固定后 0.8 秒内的滚动结算不改变锚点，避免跳转动画把它带走。

`POST /api/documents/{id}/translations/chapter-status` 按与“翻译本章”相同的章节边界统计段落状态：EPUB 传 `location`，PDF 传章节页码范围。返回 `key`、`title`（EPUB 的目录标题，无目录时取章首文字；PDF 为空，由阅读器取大纲标题或页码范围）以及 `idle`、`pending`、`running`、`complete`、`failed`、`unparsed`、`parsing`。前端在锚点、处理状态或译文更新后重新获取，有进行中的段落时每 3 秒轮询一次。

按钮规则：本章有排队或进行中的段落（或正在解析本章页面）时为“暂停翻译”，暂停后为“继续翻译”（重新请求本章）；还有未请求的段落或未解析的页时为“翻译本章”；其余为完成状态。失败段落算作完成，只在译文位置保留各自的“重新翻译”，工具栏不再显示“重试翻译”。在当前章节内看到翻译完成时显示“翻译完成”3 秒，之后只保留勾；直接进入已完成章节只显示勾。悬停勾显示“翻译完成：章节名”，PDF 没有目录时为页码范围。

`POST /api/documents/{id}/translations/chapter` 接受 `location`（EPUB 的 `href`、可选 `blockId`、`locator` 和字符范围），返回 `queued`、`characters`、`hasMore`。位置不使用 PDF 页码。PDF 提取文字的修正规则只用于 PDF，EPUB 译文中的原句保持严格对应。

本次合并验证：类型检查、构建和 Go 全套通过；Vitest 469 项通过、4 项跳过，Windows 代理一项报 `PowerShell unavailable`，在主线 `478214d` 单独复现。最终 EPUB 适配器、阅读区和任务控制专项 41 项通过。独立书库 HTTP 检查确认原创样本的 3 章、19 个正文段落导入后均为 `idle`。未调用真实模型或进行桌面视觉验收。

## 段落 block 与点击聚焦（2026-10-26）

EPUB 不经过 Paddle 版面解析：清理后的章节本身就是段落 DOM，`data-epub-block` 元素（或混合容器中共享 `data-epub-run` 的文字片段）即一个 block，与 `/epub-blocks` 使用同一 ID。`readers/epub-block-focus.ts` 按这些元素的实际排版位置绘制方框，四周留出少量间距，沿用 PDF block 的样式类、浅色/纸张/深色配色。

- 鼠标停在段落上显示 hover 框；原文译文模式下，任一侧 hover 都会在另一侧标记对应段落。拖选、已有选区、链接和按钮上不显示。
- 点击段落（按下与松开位移不超过 5px、没有选区、不是链接或已有批注）后，两侧各自平滑地把该段垂直居中，高于视口的段落顶部对齐；定位期间显示灰色背景和边框，完成后淡出。动画 240ms、三次缓出，与 PDF 一致；EPUB 可重排，不缩放。译文段落支持点击和 Enter/空格聚焦。
- 每帧重新测量位置，上方章节懒加载造成的位移不会让终点偏离。滚轮、键盘、新的点击和切换模式会中断定位；系统减少动态效果时直接定位、不显示方框。聚焦期间的程序滚动不会触发反向同步。
- hover 框右上角沿用 PDF 的按钮：文字段落提供「复制此段」「询问 AI 此段」；插图另有「放大查看原图」，复制和询问 AI 改为「复制图片」「AI 解释此图」。插图以 PNG 形式经与 PDF 相同的 `assets/{blockId}.png` 地址提供（服务器把 JPEG/PNG/GIF 转为 PNG），预览、复制和聊天图片附件共用 PDF 的流程；EPUB 插图没有页码，标题显示「书中插图」。按钮上的指针和点击不会触发段落聚焦。

## 主文档渲染器：第一步（2026-10-09）

当前 EPUB 入口改用 `readers/epub-web.ts`，将服务端白名单清理后的章节放入应用主文档，不创建 iframe。Readium Go Toolkit 继续解析出版物；旧前端适配器、依赖和两个补丁仍保留，当前入口不使用它们。下文其他章节记录此前 Readium 阶段的实现与验证。

`GET /api/documents/{id}/epub-chapters` 返回阅读顺序、目录、字符长度和段落；`GET /api/documents/{id}/epub-chapter?href=…` 返回清理后的 HTML。两者沿用本机 API 鉴权。正文与 `/epub-blocks` 使用同一次遍历生成块 ID，先计算原始 DOM 位置，再附加 `data-epub-block` 和文字范围标记。仅保留语义标签及少量属性，不应用出版方 CSS；本地图片改写为带鉴权的出版物资源地址，外部资源、脚本、事件和样式属性被移除。插入时移除书籍的原始 DOM ID，保留独立片段索引用于章内链接。

正文按章节懒加载。未加载章节以字符数、段落数和图片数估计高度；远处章节回收为实测高度占位。章节加载、图片尺寸变化及主题重排时补偿可见锚点。隐藏的原文窗格不预加载全书。目录、章内/跨章链接、HTTP(S) 外链、搜索、选区工具栏、持久批注、章节 AI 上下文及双向原文/译文滚动继续使用现有工作区接口。译文独立应用字号、字体和字重，外观面板提供同一套译文字体控件。

新位置保存 `href`、`blockId`、UTF-16 `start/end`；跨段或跨章选区另存 `endBlockId`。旧 locator 在前端按章节内 `textRange` 重叠或唯一引文解析，仅在内存中使用，不批量迁移数据库。单纯打开旧进度不会自动保存新格式。定位不明确的笔记保留并提示，后续主动阅读仍正常记录进度。Go 测试检查位置边界和新旧记录保留；实际旧位置解析位于适配器，因此在 Vitest 中验证。

第一步只支持横排、从左到右的可重排 EPUB；遇到固定版式、竖排或 RTL 声明显示中文错误。暂不包含分页、句子悬停、双语关联句子标记、DRM、位置批量迁移或旧 Readium 依赖清理。超长单章内部尚未再分块虚拟化。没有进行浏览器自动化或桌面视觉验收。

## 使用范围

EPUB 在现有原文阅读区显示。目录、纵向滚动、字体和主题继续由 Readium 处理。划词工具栏、笔记列表、批注编辑/删除与 AI 引用沿用主线已有交互。首次调研后主线已经接通正文高亮的点击和悬停，本分支复用该实现。

本版补齐以下行为：

- 跨粗体、链接、段落，以及以元素为起止边界的选区，归一化为文本节点与 UTF-16 字符偏移；不向正文插入标记节点。
- 同时保存精确 DOM 范围、原文和前后文。恢复时核对内容；路径失效后只接受唯一匹配。定位不明确时保留数据库中的笔记、跳过错误高亮并提示。
- 高亮与笔记跳转使用同一份经过核对的精确范围，避免重复文字跳到首个匹配。
- 搜索按章节内每次出现生成精确位置，最多返回 100 项；支持大小写不同的匹配和查询中的连续空白。跨块文本如果在索引与 DOM 中使用了不同的空白规则，仍可能无法生成对应结果。
- 键盘选区经 Readium 的 frame 事件通道进入原有划词工具栏。
- 批注异步恢复使用版本检查，避免删除后被旧请求重新绘制；关闭阅读器时取消资源请求和待完成导航。
- Go 校验内外层章节位置的一致性、范围及进度字段；兼容旧版空 locator。批注定位错误不会阻止正文打开。

## Readium 补丁

`pnpm-workspace.yaml` 与 lockfile 记录两个固定版本的补丁，`pnpm install --frozen-lockfile` 会自动应用：

- `patches/@readium__navigator@2.11.1.patch`：存在 domRange 时，`loadLocator` 向 frame 发送完整序列化 Locator；精确跳转失败不降级为章节进度。
- `patches/@readium__navigator-html-injectables@2.8.4.patch`：分页、滚动、竖排和 WebPub 的 `go_text` handler 接收完整 Locator，沿用原有 Range 解析及滚动逻辑；旧消息格式继续有效。

补丁同时包含 npm 包的 `src` 和实际执行的 `dist`。minified dist 是整行 diff，因此补丁文件字节数大于逻辑改动。`epub-readium.test.ts` 实际加载安装后的 dist，将 Navigator 发出的消息交给真实 Snapper handler，验证长段落内重复文字的字符偏移。测试模拟几何尺寸，不代表浏览器排版已验收。

升级 Readium 时先检查上游是否已经贯通精确 Locator，再移除或重做补丁。不能只更新 shared 或只保留一半补丁。

## 全文译文接入

EPUB 与 PDF 共享译文状态、生成批次、逐段保存、重试和 SSE 订阅。EPUB 从清理后的章节中提取有序段落及本地图片，以章节路径、DOM 范围和 UTF-16 偏移定位原文。新增 `GET /api/documents/{id}/epub-blocks`；原有 translations GET/POST/stream 同时支持两种格式，事件格式保持一致。

阅读区提供「仅原文 / 原文译文 / 仅译文」、调整栏宽和交换两侧。原文交给 Readium，译文按全书阅读顺序连续排列；滚动和选句通过段落及句子范围对应。仅译文模式下，目录、章节切换、阅读进度和 AI 当前章节上下文使用 EPUB 位置。译文显示本地图片，但不复刻原书的复杂版式，也不新增图片 OCR。

译文划词复用原有高亮、下划线、笔记及 AI 引用工具栏。批注保存译文字符范围、原文位置、段落 ID 和原文版本；跨段批注在原文中生成多处标记，仍归属同一条笔记。原文相同的两处译文批注不会被原文下划线合并规则误合并。已完成段落在失败重试和重开数据库后保留；旧 EPUB 导入记录在启动时进入共享翻译队列。

新增回归覆盖重复段落与 emoji 偏移、图片顺序及路径边界、部分翻译失败后的续传、源版本失效、译文批注重开与删除、多处原文标记的点击 ID、阅读模式切换、原文/译文选区切换、订阅释放和仅译文模式的章节上下文。PDF 原有回归测试继续通过。

真实 HTTP 加 DOM 定位检查：`MAKE.epub` 的 1,419 段文字全部按保存的 Locator 恢复为相同原文，80 张本地图片可读取。127 个原文章节中，126 个含文字或本地图片；另一个只有加载动画，没有可翻译正文。此检查没有执行浏览器排版。

## 纵向滚动

EPUB 固定使用 Readium 滚动模式，包括已有 `scroll: false` 的偏好记录。阅读区移除左右翻页按钮、分页切换和页面边缘点击翻页。原文仍由 Readium 按章节加载，滚到章末继续下滚进入下一章，章首上滚回到上一章末尾；支持滚轮、触控滑动及上下/PageUp/PageDown 键。一次触控板惯性手势只跨一个章节，避免连续跳过短章。目录、原文位置和批注仍使用原章节 Locator。

译文区直接连续排列各章，不再显示上一章/下一章按钮。跨章选区保存每段对应的原章节位置。快速滚动期间保留最近的原文同步目标，当前导航完成后再跟随，避免丢掉最后一次滚动位置。

回归覆盖章内滚动、双向跨章、加载期间和跨 frame 的惯性保护、嵌套滚动区、选区与输入框、监听器释放、旧分页偏好覆盖，以及译文跨章选区。此模式仍需人工检查触控板手感和章间加载；固定版式/竖排等出版物的限制保持不变。

## 人工验收

运行 `python3 scripts/create-epub-check.py` 生成 `.neoread/epub-check.epub`。文件完全使用项目原创测试文字，包含重复句子、跨节点内容、中文/emoji/ruby、长段落与脚注。

1. 打开「EPUB 批注验收样本」，给第一章第二处重复句添加高亮、下划线或笔记。
2. 调整字号、行距及窗口宽度，上下滚动跨章，再关闭并重新打开。
3. 点击笔记回原文，确认目标仍为第二处；点击正文批注，检查编辑与删除。
4. 跨粗体、链接和两个段落划词；第二章选择长段落靠后的文字，检查返回时的滚动位置。
5. 搜索 `NeoRead`，逐一打开结果；删除批注后切章返回，确认没有旧高亮。

可在独立测试书库启动已构建的预览，端口 `0` 会自动选择空闲本机端口：

```sh
./apps/desktop/bin/neoread-server --data .neoread/epub-preview --port 0 --web apps/web/dist
```

启动行返回 `url` 与当前会话 `token`，使用 `<url>/#token=<token>` 打开。此命令使用隔离书库。正式 Electron 的字体、原生窗口与缩放仍需人工检查。

## 本版限制

固定版式、RTL、中文竖排和复杂脚注尚未用真实出版物人工验收；协议测试通过不构成这些版式的支持认证。纯图片 EPUB 没有新增 OCR。原文跨章节的单次连续选区、DRM、内容版本迁移不在本版实现范围。失效笔记可保留和删除，尚无手动重新绑定原文的界面。
