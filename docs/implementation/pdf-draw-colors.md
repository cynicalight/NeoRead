# PDF 绘制时配色与高清预加载

## 渲染入口

`pdf.ts` 为 PDFViewer 提供 `getReaderColorAdapter(pageNumber)`。每次页面、局部高清画布开始绘制时获取当前配色快照。`pdf-link-preview.ts` 使用同一个工厂，直接渲染目标裁剪区域，避免先渲染整页再裁剪。

`pdf-draw-colors.ts` 在 PDF.js 实际绘制 `fill`、`stroke`、`fillText`、`strokeText` 等操作前映射源颜色，绘制后恢复原始图形状态。文字边缘由浏览器基于最终颜色生成，不对抗锯齿后的整页 RGB 再做 HSL 映射。深色像素 Worker、页级读取、回写、等待 Worker 而隐藏 Canvas 的 CSS 均已移除。

渐变映射源颜色停靠点，网格渐变映射源顶点颜色；图案通过 PDF.js 的图案绘制器生成所需配色版本，不把混有图片的图案当作统一文字颜色。透明组沿用 PDF.js 合成，软蒙版定义的颜色不参与深色映射。位图蒙版（包括部分 Type 3 字形）沿用 PDF.js 生成的形状，仅在绘制该局部源时使用 Canvas 滤镜，不读取整页像素。

## 图像策略

- 自适应：矢量内容在绘制时映射，普通位图保留原色并补白底；扫描页保持原图，不再对位图背景做泛洪识别。
- 保持原色：版面解析得到的 image/chart 区域补白，区域内使用原始绘制颜色，区域外映射正文。通过几何裁剪分别绘制，不复制整页像素。解析尚未提供该页版面时保留原页。
- 全部反色：正文使用阅读调色板；图形区域对源颜色简单反色，位图在绘制时使用 `invert(1)`。

图片白底排除此前图片的背板区域，避免后绘制的透明图片擦除已绘制图片。图像与正文复杂重叠、特殊混合模式的最终视觉效果仍应使用真实 PDF 人工检查。

## 分辨率、预加载和释放

- 保留 PDF.js 按 `devicePixelRatio` 选择输出比例的流程。Windows 显示缩放变化或跨屏移动时监听分辨率变化并重新绘制。
- 每张基础画布上限为 16,777,216 像素、单边 16,384，普通阅读不再使用此前 4M 上限及附加的二次降采样。超大倍率继续使用 PDF.js 局部高清画布及其视口外扩区域。
- 使用单一 PDF.js 渲染队列，优先可见页与高清区域，再准备滚动方向两页、反方向一页。离开页面的渲染会按原有队列让出执行权，不建立第二个整页渲染队列。
- 缓存通常为四页，多个页面同时可见时相应扩大，以容纳可见页和相邻页。由 PDF.js 原有缓冲区淘汰并释放画布。基础画布通常最多约 64 MiB/页；局部画布、纹理副本、PDF 图像解码会额外占用内存，此设置不是整个进程的显存硬上限。
- 内部链接首次预览直接绘制裁剪区域，按显示像素密度请求尺寸，限制为 8M 像素及单边 8192。只保留四个最近的预览结果。主题变化取消渲染，并检查版本，防止旧结果返回。

未缓存页面的突然跳转和极高倍率的快速拖动仍需要实际渲染时间；该改动不承诺任意文档、任意速度都能瞬时显示高清。

## PDF.js 升级

扩展通过 `patches/pdfjs-dist@6.3.289.patch` 和 pnpm 的 `patchedDependencies` 固定到指定版本，作用于 Web 使用的现代构建，默认不启用。不修改全局 Canvas 原型，未传适配器的原图导出、服务端处理等调用继续使用原始绘制。

升级 PDF.js 时需要重新检查 `CanvasGraphics` 的实际绘制调用、组与蒙版入口、图案生成、Viewer 的渲染上下文及优先队列。依赖补丁无法套用时安装应直接失败，不能静默退回页面像素处理。

## 手动验收

在该工作树运行 `pnpm dev`，或构建后运行 `pnpm --filter @reader/desktop start`。

1. 用含黑灰正文、彩色文字、公式、表格、照片、透明图片、矢量图及渐变的论文，在浅色、深色、灰色间反复切换，检查背景、正文、选择和高亮。
2. 在三种图像策略间切换，检查透明图片白底、图内文字和扫描页；“自适应”中的普通位图应保持原色。
3. 在适合页宽、100%、200%、400% 下上下快速滚动并反向；比较普通倍率的文字清晰度，检查高倍率局部画布更新。
4. 快速连续切换主题和倍率，确认不会出现旧配色覆盖新页面；打开论文中的引用及图片链接预览，确认颜色一致。
5. 在 Windows 100%、125%、150%、200% 系统缩放下检查文字；有多屏时把窗口移到不同缩放比例的屏幕，确认重新绘制。彩边改善必须在 Windows 实机验收，不能由 macOS 类型检查或构建结果代替。

按本次用户要求不运行测试；类型检查和构建单独记录交付结果。
