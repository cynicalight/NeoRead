# EPUB 段落位置与旧数据迁移

正文位置统一使用章节 `href`、稳定的 `blockId` 和段落内 UTF-16 `start/end`。
跨段落使用 `endBlockId`，跨章节补充 `endHref`。目录和阅读进度允许仅有章节锚点或比例。
段落位置另带 `order: {chapter, block}`：两个从 0 开始的序号分别表示出版物章节顺序和章内块顺序（包含图片块）。读取章节时即可生成，无需解析前面章节。新批注随位置保存该字段，合并范围变动时同步更新为起始块的顺序；批注列表直接按已存顺序、原文偏移和原文/译文侧排序，不请求整书段落。
缺少序号的历史批注及未解析批注仍保留，放在已有顺序的批注之后，按创建时间和 ID 稳定排序；不为补序号重跑已完成的迁移。首次迁移本来就要读取原文时，可顺带给成功转换的段落锚点写入序号。

段落 ID 仍由原章节路径和原始 DOM 起止位置生成，算法没有变化。不得通过排序 ID 判断阅读顺序。

新创建的位置和段落 API 不再输出 Readium locator；尚未迁移的历史记录仍保留该字段。前端不依赖 Readium Navigator；Go 的 Readium EPUB 解析保留。
段落解析器仅在内存中保留旧文本范围索引，供迁移使用，不生成或发送序列化 locator。

## 升级

启动时按文档迁移一次 EPUB 位置。更新和迁移版本在同一事务内提交；完成后的文档在后续启动时直接跳过，打开批注列表也不会重试迁移。
迁移覆盖批注、阅读进度、文档导航、聊天消息和运行记录内的结构化位置；不会解析正文字符串内的 JSON。

使用原章节的文本偏移或 DOM 起止点恢复范围，并校验引用文字；必要时采用包含上下文约束的唯一文字匹配。
支持 UTF-16、跨段落和空白归一化。重复文字无法唯一定位时，不选择第一个匹配。

每本书的更新及原始记录备份在同一事务内提交。`epub_location_backups` 保留首次修改前的完整记录，
记录批注 ID、笔记、颜色、标签等内容。成功位置移除 locator；反复执行不会重复改写已迁移位置。
源文件暂时无法读取时，旧位置也会标记为未解析，并记录该文档的迁移已完成。这是当前接受的旧数据限制；数据库写入失败则会回滚，不标记完成。

无法可靠转换的位置保留原始 locator，并设置 `unresolved: true`。批注列表显示“定位异常”，
正文不绘制该范围，跳转给出提示，笔记和引用文字仍可查看、编辑、导出。即使之后重建 EPUB 缓存，也不会自动重试或移除异常标记；位置恢复留给用户手动处理。
这类记录不参与自动去重。不要删除无法转换的旧批注。

迁移日志记录开始、完成/部分完成/失败、源不可用、转换数量、未解析数量和耗时，不写正文、笔记或路径。

## 混合选区

重排模式跨段选择同时经过原文和译文时，分别提取两侧的文字和范围，保存为两条独立批注。
原文引用仅取段落原文，译文引用仅取译文范围，不包含夹在中间的另一侧文字。
聊天引用和 AI 操作使用的通用选区文字保留实际选中的原文及译文；批注仍使用各侧独立的文字和位置。
两条记录各自高亮、删除和撤销。若其中一条保存失败，保留已保存的记录，重试只提交尚未保存的部分。
仅原文或仅译文模式不记录隐藏的一侧。

## 合并及缓存

高亮、划线按现有类型、颜色、标签和关联信息规则检查兼容性；范围比较使用段落位置及书籍顺序。
重复、包含和重叠范围可合并，相邻范围不合并。译文坐标保持独立，不能用原文范围替代。
保存时只合并本次新批注及其重叠对象，不批量合并无关旧批注。合并和迁移修复引用时均跳过图片块，不将 alt 文本作为正文引用。
章节段落优先复用阅读时生成的内存缓存。缓存最多保留 32 个章节，章节文件大小或修改时间变化时失效；合并需要而缓存缺失时，仅解析相关章节，不重新解析整本书。
EPUB 原文索引增加格式版本，使旧缓存按需重建；PDF 索引版本不变。

## 人工验收

在隔离书库中打开含旧高亮、划线和笔记的 EPUB。检查普通和重排视图的高亮、笔记内容及引用跳转。
重复标记同一原文应只有一条记录；扩大选区应合并；不同颜色保持独立。检查跨段落、中文、emoji、删除和撤销。
检查旧阅读进度、目录、译文联动和聊天原文引用。无法定位的批注应显示“定位异常”并保留内容。
重启后重复上述检查，确认迁移结果稳定。不要用真实书库作为首次迁移试验环境。
