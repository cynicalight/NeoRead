# 导出与导入书库

桌面版在“设置 → 论文库”提供“导出书库”。选择全部书库、全部论文、全部图书、普通分类或智能标签分类后，选择 ZIP 保存位置。普通分类包含子分类中的文档。

全部导出默认文件名为当前书库名称加 `.zip`，论文或图书分别为 `NeoRead论文库.zip`、`NeoRead图书库.zip`；分类使用分类名称加 `.zip`，嵌套分类使用最后一级名称。可在系统保存窗口中修改名称。

压缩包保留原始 PDF/EPUB、论文信息、每篇文档原来的添加日期、分类与标签、批注和阅读位置、笔记、对话、已保存的译文与 LaTeX、图片和解析缓存、附件、概要及搜索索引。新建恢复和合并均保留添加日期，不会将所有文档改成导入当天。全部导出也包含回收站文档。AI 账户、API 密钥、代理和机器集成配置需在目标机器单独配置。

对话包含每篇文档的全部会话及名称、消息顺序和原时间、引用、图像附件、阅读位置、思考内容、来源和工具记录。导入后的 Codex 会话会在下一次提问时从这些已保存记录重建，不依赖原机器的 Codex 线程，也不会与原书库共用线程。编辑或撤回后的当前记录同样随书库迁移。

导出前先保存当前阅读状态，然后在线创建数据库快照并逐文件压缩。应用窗口、阅读和 AI 调用继续运行，无需重启；快照包含开始导出时已经保存的数据。文件删除及解析缓存发布会等待快照完成。下载完整保存后才替换目标 ZIP，失败时清理临时文件并保留原来的压缩包。

点击导入或导出后，先选择 ZIP 文件或保存位置；取消选择不会开始处理。选好路径后才显示处理窗口，可选择“后台运行”，关闭设置后继续阅读；右下角显示任务状态。后台导入完成后点击“切换到新书库”再切换，切换前会保存当前阅读状态。前台导入完成后自动切换。

“导入书库压缩包”提供两种方式：

- **新建书库并切换**：只需选择一次 ZIP，应用自动在自己的书库目录中创建独立书库，完整还原压缩包中的内容。
- **合并到当前书库**：保留当前书库中压缩包未包含的文档，合并结果保存为新的独立书库。同一文档 ID 以压缩包版本为准，包括译文、批注、笔记和对话；分类定义合并，同名或同 ID 定义使用导入版本。

两种方式都保留原书库，不再要求第二次选择目录。先在临时目录解压、检查数据库关联和原文件、恢复索引，再切换保存位置；失败时丢弃未完成的导入，继续使用原书库。正常导入和书库切换只更换本地书库服务并重新加载阅读窗口，应用进程无需重启；仅书库恢复模式或连接恢复失败时使用重启兜底。导入准备期间当前阅读与 AI 调用继续运行，合并从当前书库的已保存快照创建新库；准备期间产生的新修改保留在原书库。进行中的 AI 调用在切换书库时中断，已保存的结果保留，未完成任务按现有恢复规则处理。

左上角标题下拉列出已登记的书库，可切回原书库；下方仍可选择当前书库的论文或图书视图。新书库默认使用 ZIP 文件名作为名称。双击标题可以重命名，按 Enter 或移开焦点保存，Esc 取消；重名自动追加 `(1)`、`(2)` 等后缀。重命名只修改显示名称，原文件、数据库和添加日期保留。

PDF、EPUB 和图片直接写入 ZIP，避免重复压缩已有压缩数据；数据库和文本使用快速压缩。合并时移动已校验的临时文件，减少再次复制，并批量保存索引路径。压缩包可能变大，但仍保留 CRC、路径和数据库关联检查。

已有文件夹书库仍可从“书库位置 → 导入书库”直接打开。

## 手动检查

1. 给示例论文添加批注与笔记，打开译文，导出全部书库。
2. 选择“新建书库并切换”，选择一次 ZIP 即开始导入，确认原文、译文、公式、批注、笔记和分类一致，添加日期保留原来的值。
3. 从另一份已有书库选择“合并到当前书库”，确认已有的其他文档保留，同一文档使用压缩包中的内容，原目录仍可直接打开。
4. 导出一个有子分类的分类，导入后确认相应文档齐全、其他分类文档未包含。
5. 从左上角标题下拉切回原书库，再切到新书库；双击标题重命名为已有名称，确认自动添加后缀。
6. 在导入和导出时点击“后台运行”，确认可以继续阅读；后台导入完成后应由用户点击切换。
7. 导出时继续阅读，确认导出完成后窗口与标签仍可使用。取消文件选择，确认书库与窗口继续可用；选择无效 ZIP 时应报告错误并保留原书库。
