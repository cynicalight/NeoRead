# 多文档标签页

多文档标签页默认关闭，在“设置 → 阅读交互 → 多文档标签页”中开启。关闭时打开文档会替换当前文档，返回书库会释放阅读器，重启后停在书库，批量选择中也不显示“在标签页中打开”。开启状态下关闭此选项，会关闭当前文档以外的标签，有未发送内容时先确认；取消或有批注正在保存时，选项保持开启。

打开论文或图书时会创建文档标签，重复打开同一文档会切换到已有标签。点击顶部“书库”或阅读工具栏的返回按钮可回到书库，已打开的标签继续保留。点击“+”可查找并打开其他文档。

书库入口固定在标签栏左侧，文档较多时可从右侧“标签页列表”切换。右键标签可关闭当前、其他或右侧标签，也可用鼠标中键关闭。批量关闭会统一确认未发送内容；其中有批注正在保存时，整组标签暂不关闭。

拖动标签可调整顺序，拖到标签栏边缘时自动滚动；右键菜单的“向左移动”“向右移动”也可调整。标签较多时会一起收窄，长标题末尾淡出；非当前标签过窄时隐藏关闭按钮，再窄只显示图标，超出最小宽度后标签栏可横向滚动（支持滚轮）。用鼠标连续关闭标签时，其余标签宽度保持不变，直到指针离开标签栏，方便逐个点击关闭。新开和关闭标签带有展开、收起动画；系统开启“减弱动态效果”时不播放。

误关后可从标签菜单重新打开，本次批量关闭的标签会一起恢复到原顺序。恢复的是文档和已保存的阅读记录，不会恢复关闭时确认放弃的草稿。

在论文库或图书库进入批量选择，选中多份文档后点击“在标签页中打开”，可一次创建多个标签。首次只加载选中的文档，其他标签在第一次切换时加载。

切换标签保留当前阅读器、原文／译文模式、未发送的问题、附件和对话状态。正在生成的回答会继续接收，不会因为切换或回到书库而中断。关闭标签会释放该文档的阅读器，后台会话中的回答继续生成，可重新打开查看；存在未发送内容或正在生成的回答时会先确认。批注正在保存时须等待保存完成。进度保存失败时保留标签，避免丢失阅读位置。

已打开的文档顺序及当前选中的文档随书库设置保存，重启后恢复。未发送的草稿仅在本次运行中保留；后台回答及保存状态由现有会话机制恢复，恢复标签不会自动重复发送问题。删除或合并文档时，相应标签会关闭，其他标签不受影响。

## 快捷键

- `Ctrl+Tab` / `Ctrl+Shift+Tab`：下一个／上一个文档标签。
- `Cmd+1`—`Cmd+8`（Windows 为 `Ctrl`）：切换到对应文档标签。
- `Cmd+9`（Windows 为 `Ctrl`）：切换到最后一个文档标签。
- `Cmd+Shift+T`（Windows 为 `Ctrl+Shift+T`）：重新打开最近关闭的标签或一组标签；仅保留本次运行的关闭记录。
- `Cmd+W`（Windows 为 `Ctrl`）：关闭当前文档标签；在书库界面保留原生关闭窗口的行为。

## 人工验收

0. 在设置中开启“多文档标签页”；关闭时确认打开文档会替换当前文档且不显示标签栏。在多个标签含草稿时关闭此选项，确认会提示，取消后选项保持开启。
1. 批量打开三篇论文，确认顶部显示三个标签；再次打开其中一篇应定位到已有标签。
2. 调整各篇阅读位置、双语模式并填写不同的未发送问题，反复切换后确认各自内容仍在。
3. 生成回答时切换到另一篇或书库，再返回确认回答继续接收；关闭正在生成或含草稿的标签，确认可以取消关闭。
4. 关闭后台标签应保持当前文档；关闭当前标签应选择相邻文档；关闭最后一个标签应返回书库。
5. 重启应用，确认标签顺序、选中的文档和已保存的阅读位置恢复；回收站文档不应重新打开。
6. 打开五个以上标签，拖动标签到新位置并确认重启后顺序保留；把窗口收窄，确认标签同步收窄、标题淡出、标签栏可滚动。
7. 用鼠标连续点击关闭按钮，确认指针离开标签栏前其余标签宽度不变。
8. 检查窄窗口、长标题、横向滚动、浅色／深色／跟随系统，以及 macOS 红绿灯、拖动窗口和关闭标签快捷键。
