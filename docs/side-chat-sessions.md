# Side chat 多会话

打开任一 PDF/EPUB，在右侧 Agent 面板顶部选择会话，点击加号新建，铅笔按钮重命名。后端统一在设置中选择 API、Codex、Claude Code 或 Kimi；侧栏不再提供后端选择器。API 会话由 pi 执行。旧记录自动归入默认会话。

会话之间的问题、上下文、引用和输出独立。可以在会话 A 等待回答时切换到 B 提问，再切回 A 查看进展。关闭侧栏或切换文档不会停止生成；只有点击停止、删除文档或退出 NeoRead 才会中断相应运行。最多四个会话同时运行，同一会话一次只处理一个问题。退出应用后的在途请求不会在下次启动时自动重发。

悬停或聚焦自己的问题后可选择“编辑问题”或“撤回问题”。编辑保留原引用、图像附件和阅读位置，确认保存后重新生成；撤回把问题、引用和附件放回输入框，并与已有草稿合并。操作前会提示移除的回答及后续消息数量，其他会话不受影响。生成中先点击停止，等待保存状态核对完毕后再操作。关联已移除回答的批注保留原文和笔记，恢复为未回答状态。

选中聊天问题或回答中的文字后，点击悬浮条的“引用到对话”，会在输入框上方显示引用条，与原文、译文引用共用同一组操作；可移除引用，草稿文字保持不变。发送时携带所选对话，切换会话或撤回问题时保留相应引用。选中文字时暂停自动跟随新回答，点击底部箭头恢复。

各会话的新消息和重新生成使用设置中当前选定的后端；模型与 Effort 复用对应后端的偏好。已开始的运行保留开始时的配置，切换设置不改变在途请求。API 的 key/地址和 CLI 的登录方式继续在原设置中配置。论文仍是阅读单元，此功能不提供项目目录、终端或自动写文件。

## 开发验证

在任务 worktree 执行 `pnpm install --frozen-lockfile`、`pnpm typecheck`、`pnpm test`、`pnpm build`。`pnpm dev` 会同时构建并启用 pi worker；直接启动 Go 时需设置 `NEOREAD_NODE` 与 `NEOREAD_AGENT`，后者指向 `apps/agent/dist/main.mjs` 的绝对路径。

1. 导入 PDF 或 EPUB，确认默认会话里的旧消息、来源跳转、批注关联保持可用。
2. 新建两个会话，分别问两个不同问题。在 A 出流时切到 B 发送，确认两者都继续运行。
3. A 运行时切换论文或关闭侧栏，再回到 A，确认可以继续查看输出与最终保存结果。
4. 同时运行 A/B，停止 A，确认 B 正常完成；重命名和切换不会改变各自的上下文。
5. 刷新页面时保留正在运行的会话，确认接回同一 run；退出 NeoRead 再打开，确认未完成问题显示可重试，没有自动重复发送。
6. 在设置中分别切换 API、Codex、Claude Code、Kimi，确认已有会话和新会话的下一次发送都使用当前设置；使用选文、PDF 图表附件与 EPUB 阅读位置继续提问，核对增量输出、来源与定位。没有对应 CLI 或有效账号时，该项需要在配置后的环境验证。
7. 使用 Codex 会话的“在 Codex 中继续”，确认导出的是当前会话的独立副本。
8. 在空会话输入中文和长问题，持续阅读或后台处理一段时间后再次输入，检查候选组合、粘贴和光标响应；切换会话后草稿仍在。选中旧回答的一段文字，点击“引用到对话”，确认选文显示为可移除的引用条，草稿文字保持不变；在流式回答期间选文，确认选区不会被自动滚动带走。

自动化测试使用本地模拟模型服务和 CLI 协议进程，不调用付费模型或读取真实 CLI 凭据。视觉和真实账号验收需按上述步骤手动完成。
